# amo-proxy

Связывает дашборд с AmoCRM. Когда преподаватель нажимает «Был на уроке»:
ChatGPT пишет обратную связь → она уходит примечанием в сделку → сделка
переезжает на этап «Прошел ОУ».

Раньше это жило в Apps Script, но там дневная квота на исходящие запросы
общая с синхронизацией таблицы — синк её выедал, и во время урока отметка
переставала работать. Здесь таких ограничений нет.

## Развёртывание на Railway

1. Railway → **New Project** → **Deploy from GitHub repo** → выбрать
   `SuperKid-academy/sales-dashboard`
2. **Settings → Root Directory**: `amo-proxy`
3. **Variables** — добавить:

   | Переменная | Значение |
   |---|---|
   | `AMO_ACCESS_TOKEN` | токен AmoCRM (или `AMO_TOKEN` — читается любой) |
   | `OPENAI_API_KEY` | ключ OpenAI |
   | `ALLOWED_ORIGIN` | `https://dashboard.superkid.uz` |

   Если в проекте уже есть `AMO_ACCESS_TOKEN` и `OPENAI_API_KEY`, добавить
   нужно только `ALLOWED_ORIGIN`.

   ВАЖНО: разворачивать **отдельным сервисом**. Если в проекте уже крутится
   другой код (платежи, Telegram, продления), деплой в тот же сервис его
   заменит.

4. **Settings → Networking → Generate Domain** — получить адрес вида
   `https://имя.up.railway.app`
5. В дашборде под `admin`: ⚙️ → «Связь с AmoCRM» → вставить адрес →
   «Проверить связь» → «Сохранить адрес»

Проверить, что сервис жив, можно открыв его адрес в браузере: вернётся
`{"ok":true,...}`, где `amo` и `openai` показывают, заданы ли ключи.

## Локальный запуск

```bash
npm install
AMO_TOKEN=... OPENAI_API_KEY=... npm start
```

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | статус сервиса и наличие ключей |
| POST | `/api/add-note` | `{dealId, text}` — примечание в сделку |
| POST | `/api/move-deal` | `{dealId, statusId?, pipelineId?}` — перевод по воронке |
| POST | `/api/process-attended` | оценки → обратная связь → примечание → перевод |

`process-attended` возвращает `steps` — что успело примениться. Если ChatGPT
недоступен, текст собирается из оценок преподавателя, и сделка всё равно
переезжает.

## Настройки по умолчанию

Воронка `5326345` («Детская прямая»), этап `87908298` («Прошел ОУ»).
Меняются переменными `OU_PIPELINE_ID` и `OU_ATTENDED_STATUS_ID`.

## Автопродления

Ученик, у которого в Activation осталось ≤ 2 урока, попадает в «Воронку
продления» на этап «ОСТАЛОСЬ МЕНЬШЕ 3 уроков». Если у него есть сделка в
«АКТИВНАЯ БАЗА» — она передвигается, иначе создаётся новая (поля копируются
из сделки «Детской прямой»). В сделке заполняются «Номер модуля» (за какой
платить), «Номер группы» и название «Имя, модуль N, группа G».

Пропускаются: ученики не в группе или со статусом отчислен/переведён/заморожен,
ждущие доплату за начатый модуль, оплатившие за последние 7 дней, и те, у кого
уже есть сделка на этот модуль или открытая сделка в рабочем этапе.

| Переменная | Значение |
|---|---|
| `RENEWAL_MODE` | `off` (по умолчанию) — только просмотр; `manual` — запись по запросу; `auto` — запись по расписанию |
| `RENEWAL_API_KEY` | ключ для `/api/renewal/*`: `?key=...` или заголовок `X-Renewal-Key` |
| `ACT_USERNAME`, `ACT_PASSWORD` | вход в activation.superkid.uz |
| `RENEWAL_CRON_INTERVAL_MIN` | период в режиме `auto`, по умолчанию 60 |
| `RENEWAL_RESPONSIBLE_USER_ID` | если менеджер «Бекзод» не находится по имени |

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/renewal/scan?key=` | что будет сделано, без записи в AmoCRM |
| POST | `/api/renewal/push?key=` | выполнить (кроме `RENEWAL_MODE=off`) |
| GET | `/api/renewal/status?key=` | режим и итоги последнего прогона |
